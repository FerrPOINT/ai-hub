# Приёмка первой поставки

S7 закрывает v1 только после всех FR/NFR и TC с actual evidence.

- Exact source/Base/toolchain/schema/config/image manifest и served target identity.
- Actual central SSO/session/PAT/client/project-grant readback, revocation и logout.
- Own nonempty migrations/backup/restore, ledger reconciliation и rollback.
- Каждый supported provider/account/model adapter qualified: plain/stream/tools/
  structured output/cancel/context/usage/actual model and cost confidence.
- Consumer real inference/tool continuation, request trace и budgets.
- UI all routes/states/viewport/themes, export and protected direct URLs.
- Canonical statistics sums/unknown counts, late billing/subscription/refund.
- Evaluation pinned comparability/cost/cancel/restart.
- Bounded load targets измерены и evidence limitations названы.
- Clean task source + publication/readback. Hosted CI optional mirror, no green
  local-only result вместо обязательного runtime/provider gate.

Release receipt не хранит secrets/full transcripts; ссылки на private evidence
разделены от public technical description. Tag/version только после accepted
candidate; docs baseline не release application.
