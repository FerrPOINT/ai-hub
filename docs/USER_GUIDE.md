# Руководство по проектному AI Hub

Это инструкция по интерактивному макету. Настоящие endpoints/SSO/provider calls появятся
после реализации; реальные ключи в макет не вводить. Изменения сбрасываются при reload.

1. Выберите проект Namespace в шапке. «Все проекты» — только разрешённая сводка.
2. В «Провайдеры» создайте подключение. OpenRouter — отдельный preset, ChatGPT —
   собственная подписка; её квота не равна бюджету денег.
3. Откройте каталог, найдите модель и задайте контекст для этой модели. Сохранённое
   значение вернётся при переключении. Настроенный контекст не подтверждает physical limit.
4. В «Модели» создайте профиль: разработка с явным резервом либо закреплённый тест.
   Сохраните черновик, проверьте точную конфигурацию и отдельно опубликуйте.
5. В «Приложения» задайте Namespace и разрешённые профили. Сохранение прав не выдаёт ключ:
   откройте «Ключи» и выполните отдельную выдачу. DEMO-NOT-A-REAL-KEY не работает в API.
6. После будущего вызова смотрите request ID, frozen revision и каждую попытку в «Запросы».
   Неизвестный исход требует уточнения; повтор может создать второе списание.
7. В «Расходы» разделены подтверждённые суммы, оценки, неизвестные и резерв.
   Валюты не суммируются. Подписка оплачивается за период один раз.
8. В «Тестирование» сохраните набор и сравните закреплённые версии. Новый запуск имеет
   собственный ID; отсутствие стоимости не означает бесплатный лучший результат.

Уведомление объясняет scope, событие и допустимое действие. Подтверждение не освобождает
резерв и не увеличивает бюджет. Ошибка чтения сохраняет последние данные с отметкой времени.
Пример будущего consumer flow: [CONSUMER_V1](contracts/CONSUMER_V1.md).

## Настроить тарифы

Откройте «Тарифы». В «Себестоимости подключений» выберите automatic для OpenRouter либо manual для Ollama Online/ChatGPT по подписке и задайте rates за 1M input/output. Для проекта выберите Namespace и настройте markup (20% default) либо собственные ставки. Создаётся новая revision для новых requests; история и provider расходы сохраняются. [Правила](PROJECT_TARIFFS.md).
