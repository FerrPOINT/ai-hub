# ADR-0008: выделение AI и Namespace

Дата: 2026-10-09. Статус: Target approved для документации/design.
Admin сохраняет registry/branding/identity bridge/service catalog. Hub владеет AI
settings/authorisation/requests/financial evidence. После accepted cutover /ai —
переход в Hub, без второго редактора. Credentials reauthorize по умолчанию.
NamespaceRef технический Base тип; ресурсы остаются у owners. Global connections/profiles
переиспользуются клиентами с проверенными bindings. Старый SDK pin не изменяется
ради документов. Дизайн моделирует исходные настройки Admin и pending/unknown.
Альтернатива второго readonly финансового dashboard в Admin отклонена пользователем:
требуется карточка состояния и переход. Перенос общего vault/shared DB отклонён.
Новое приложение и cutover — будущие S1–S7 gates, не эффект этой поставки.
